Before you install

Experimental Alpha software may contain bugs and features may change. Back up important data and review the release notes before installing.

The installer is unsigned, so Windows may show a SmartScreen warning. Confirm that you reached the official GitHub release and compare the installer checksum. Do not turn off Windows security protections.

Broader hardware and physical-device validation is ongoing. Review the release notes for the checks completed on this version.

Need assistance or have installation questions? Contact support@rovarinofficial.com.
