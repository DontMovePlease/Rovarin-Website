Before you install

Experimental Alpha software may contain bugs and features may change. Back up important data and review the release notes before installing.

If the installer is still unsigned, Windows may show a SmartScreen reputation warning. Confirm that you reached the official GitHub release and compare the installer checksum. Do not turn off Windows security protections.

Broader hardware and physical-device validation is ongoing. Review the release notes for the checks completed on this version.

What’s new

Rovarin 0.3.0

  • Quick Launch & App Launching: Instant app launch rail, search, and pinned favorite apps.
  • Real Application Icons: High-fidelity local icon extraction for Windows and Store applications with SVG fallbacks.
  • Clean App Catalog: Separation of low-level system components, sanitized publisher metadata, and responsive Grid/List views.
  • Persistent Selection Tray: Viewport-docked selection tray with live count, total size calculation, expandable review sheet, and batch uninstallation.
  • Reliability & Safety: Bounded process handling, verified PIN regeneration, and zero-npm runtime architecture.

Check your download

  1. Open this page or the official GitHub Releases page.
  2. Confirm the version and release notes.
  3. Download the Windows installer and its published SHA-256 checksum.
  4. Verify the checksum before opening the installer.
  5. Follow the installer and Rovarin setup prompts without disabling Windows protections.

SHA-256 is a file fingerprint: it lets you check that your download matches the published installer. You do not need to enter it anywhere to install Rovarin.
