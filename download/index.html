What’s new

Rovarin 0.4.0

  • Applications: Improved individual/batch uninstall, honest progress and optional leftover preview/Delete/Cancel.
  • Startup Apps: Enable, Disable and Restore for supported registrations and eligible sign-in tasks.
  • Administrator Maintenance: Included protected component, one-time local UAC enrollment and Disable to revoke access.
  • Processes: Floating End task bar, with a separate advanced process-tree action.
  • Setup: Easier local PIN Recovery and tested installer/updater preservation.

Read the full 0.4.0 release notes ↗

All eight regression suites and installer integration tests passed for v0.4.0; back up important data before upgrading.

Install or upgrade

Run the official installer on your PC. Existing users can use Settings → Updates on the Experimental channel or install over their copy. The tested 0.3.0 → 0.4.0 path preserves PIN and settings. Local recovery is under Start → Rovarin → Rovarin Setup and PIN Recovery.

Known Alpha limitations

Bing AppX removal hangs on the test PC, including direct Windows removal. Third-party service controls are deferred. Recent UI changes still need physical iPhone acceptance; Safari scroll-to-swipe takeover remains unresolved.

Check your download

Show the installer’s file fingerprint (SHA-256)

The installer is unsigned, so Windows may show a SmartScreen warning. Confirm that you reached the official GitHub release and compare the installer checksum. Do not turn off Windows security protections.

  1. Open this page or the official GitHub Releases page.
  2. Confirm the version and release notes.
  3. Download the Windows installer and its published SHA-256 checksum.
  4. Verify the checksum before opening the installer.
  5. Follow the installer and Rovarin setup prompts without disabling Windows protections.

SHA-256 is a file fingerprint: it lets you check that your download matches the published installer. You do not need to enter it anywhere to install Rovarin.
