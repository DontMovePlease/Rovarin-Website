Questions about Rovarin

Direct answers about remote Windows monitoring, phone access, Tailscale, compatibility and the current license.

What is Rovarin?

Rovarin is a Windows application that lets you monitor and control your PC from a phone or supported browser. It runs on the PC and uses Tailscale for private remote connectivity.

Can I monitor my PC from my phone?

Yes. Rovarin provides a mobile-friendly PC monitoring dashboard with CPU, GPU, memory, storage, network, processes and uptime information where available.

Can I access Rovarin away from home?

Yes. Install Tailscale on the PC and your phone or browser device, connect both to the same Tailscale network, then open the Rovarin link and enter your PIN. Rovarin does not turn Tailscale on for you.

Does Rovarin require Tailscale?

The Windows desktop app and local PIN setup work without Tailscale. For access from your phone or another device, Tailscale must be installed and connected on both devices. Wi-Fi alone is not the supported remote connection. Rovarin checks Tailscale during setup, but does not turn it on for you.

Does Rovarin upload my PC telemetry to a cloud service?

Rovarin does not require a Rovarin-hosted cloud dashboard. Telemetry is collected on your PC and shown through the locally hosted dashboard over the supported connection.

Is Rovarin free?

The current project is available for noncommercial use under its license. Review the current license before use because “free” does not remove its conditions.

Is Rovarin open source?

No. Rovarin is source-available for noncommercial use under its current project license, but it is not described as OSI open source.

Which versions of Windows does Rovarin support?

The current installer targets Windows 11 x64. Broader hardware and Windows configuration validation is ongoing; check the release notes for the tested scenarios.

Does Rovarin work on iPhone?

Rovarin is designed for supported phone browsers, but this website does not claim verified iPhone compatibility until the release documentation confirms the tested iOS and browser versions.

Does Rovarin work on Android?

Rovarin is designed for supported phone browsers, but this website does not claim verified Android compatibility until the release documentation confirms the tested Android and browser versions.

Why does Windows warn me about the Rovarin installer?

An Experimental Alpha installer that is not yet code-signed may not have established SmartScreen reputation. Verify that it came from the official release and compare its checksum. Do not disable Windows security protections.

How do I enable administrator maintenance?

In the Windows app, open Settings → Administrator Maintenance → Enable. Approve Windows UAC locally once to provision and enroll the protected component. Remote requests remain authenticated and limited to the five supported actions. Disable revokes access; enrollment cannot be started from a phone.

Can Rovarin run arbitrary commands remotely?

No. Rovarin exposes specific implemented controls such as safeguarded process termination and allowlisted maintenance actions, not a general remote command shell.

How do I get help or contact support?

If you have questions, feedback, or need help setting up Rovarin, email support@rovarinofficial.com. For bug reports, you can also submit an issue on GitHub.
