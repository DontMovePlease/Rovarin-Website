How access works ↗

Let’s get you connected

From desk to pocket.
Three little steps.

01

Install Rovarin.

Download the Windows installer, open the app and finish local setup. Your PIN is created on your PC.

02

Connect your devices.

For remote access, install Tailscale on your PC and mobile device. Sign into the same Tailscale network.

03

Take a peek.

Open the mobile address shown in Rovarin and enter your PIN. Add it to your Home Screen if you like.

Tailscale isn’t bundled. You can skip the remote setup and use Rovarin locally.

A few things to know

Before you jump in.

Is it ready for everyone?

Rovarin is an Experimental Alpha. All eight automated test suites and isolated Windows installation, upgrade, PIN recovery and uninstall lifecycle verification passed for 0.3.0. Broader hardware and physical-device testing is still ongoing; see the release notes for details. Expect rough edges and please report bugs.

Will it work without Tailscale?

Yes, on your local Windows desktop. Tailscale is needed for secure remote/mobile access in this release.

Why is my CPU temperature unavailable?

CPU temperature is optional and hardware-dependent. Rovarin provides an optional Enhanced sensor path using LibreHardwareMonitor and PawnIO. The rest of the dashboard works even when temperature sensors aren’t available.

Can I inspect or change the code?

Yes. Rovarin is source-available under PolyForm Noncommercial 1.0.0, which permits noncommercial use and modification. It isn’t unrestricted open-source software. Earlier and third-party licenses remain intact.

Why does Windows show a warning?

The Alpha installer is currently unsigned, so Windows may show a SmartScreen warning. Review the source, release notes and published SHA-256 before deciding whether to install. We don’t claim signing or reputation guarantees.
